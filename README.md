# Разведочный анализ датасета фильмов IMDb

## Описание

Разведочный анализ данных о 5000 фильмах с наибольшим рейтингом на IMDb.  
Цель — выявить закономерности и факторы, влияющие на доход фильмов.

## Данные

Датасет содержит 11 признаков:

- poster — ссылка на постер
- title — название фильма
- certificate — возрастная классификация (BBFC)
- runtime — продолжительность
- genre — жанр
- rating — рейтинг на IMDb
- about — описание сюжета
- director — режиссёр
- stars — актёры
- votes — количество голосов
- gross_earn — доход

Источник: [Kaggle](https://www.kaggle.com/datasets/totoro29/imdb-movies)

## Задачи

1. Выполнить обзор данных
2. Оценить датасет на наличие дубликатов и пропусков
3. Привести данные к необходимому для анализа типу
4. Выполнить анализ количественных признаков
5. Выполнить анализ категориальных признаков
6. Проанализировать взаимосвязи между признаками
7. Сформулировать выводы

## Инструменты

- Python 3
- pandas
- numpy
- matplotlib
- seaborn
- Google Colab

## Основные выводы

- Распределение доходов фильмов асимметрично: большинство фильмов имеют низкие сборы, небольшая часть блокбастеров приносит основную прибыль.
- Прямой линейной связи между продолжительностью фильма и доходом не обнаружено.
- Фильмы с низким возрастным ограничением (U, 12A, PG) в среднем приносят больше дохода.
- Категория 15 встречается чаще всего, но не является самой прибыльной.
- У разных режиссёров разное распределение возрастных категорий, что указывает на разные целевые аудитории.
